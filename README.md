A deterministic Node 22 program that writes one original two-sentence horror story (200 characters) to `/output/entry.txt` for make.fun's "Two-Sentence Horror" bounty ($2). No network, no randomness — the same story every run.

> Every night at eleven, my neighbour knocks twice on the wall between our apartments — our signal that he is still alive. His obituary ran on Tuesday, and tonight the knocking came from inside my flat.

## Run it

```sh
node main.ts
```
